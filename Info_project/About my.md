Sobre ML/IA: eu não começaria agora com curso muito pesado de Machine Learning matemático. Você pode estudar ML, sim, mas conectado a projeto. O melhor próximo caminho seria:
1. Python logic basics
2. Flask/routes/APIs
3. SQL/SQLite/PostgreSQL
4. Pandas reports
5. OCR and document automation
6. Basic ML classification project
Ou seja: primeiro ficar mais firme em automação + dados + web + banco. Depois entra ML para classificar documentos, por exemplo:
invoice
contract
payslip
receipt
delivery note
Aí ML entra naturalmente no seu projeto, sem virar teoria solta.
